# 星露资本 · Stardew Capital

面向《星露谷物语》与独立模拟宿主的金融经济系统实验。长期方向是让商品期货、商店股票、外汇、基金与银行连接到同一个经济世界，而不是彼此独立的随机行情小游戏。

## 当前代码与工具

- `StardewCapital.Core/`：已有价格生成、基本面/新闻配置、期货合约、订单簿和撮合相关原型。
- `StardewCapital.Tests/`：交互式控制台、模拟结果导出器及 `price_viewer.html` 离线价格查看器。
- 根目录原有《期货参考文档》《模型公式更新》《参考资料》：历史设计，保留用于理解旧价格路径模型。

当前原型不应被描述成已经完成的新多智能体市场或可直接使用的完整游戏 Mod。实际进度、已知限制与下一步验收见 [重启路线](docs/wiki/07-roadmap-and-tests.md)。

## 新方案的核心约定

**经济状态影响参与者的判断，参与者提交订单，订单簿形成真实成交，成交和风险再反馈到参与者。**

基本面、现货指数、成交价、风险标记价和结算价分开；NPC 与玩家都要承担资金、库存、保证金和流动性约束。先验证一个商品和少量规则型代理，再扩展规模与资产类别。
